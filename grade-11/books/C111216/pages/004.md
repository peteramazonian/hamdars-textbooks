# فهرست

فصل ۱ ـ تنظیم عصبی ... ۱  
گفتار ۱ ـ یاخته‌های بافت عصبی ... ۲  
گفتار ۲ ـ ساختار دستگاه عصبی ... ۹

فصل ۲ ـ حواس ... ۱۹  
گفتار ۱ ـ گیرنده‌های حسی ... ۲۰  
گفتار ۲ ـ حواس ویژه ... ۲۳  
گفتار ۳ ـ گیرنده‌های حسی جانوران ... ۳۳

فصل ۳ ـ دستگاه حرکتی ... ۳۷  
گفتار ۱ ـ استخوان‌ها و اسکلت ... ۳۸  
گفتار ۲ ـ ماهیچه و حرکت ... ۴۵

فصل ۴ ـ تنظیم شیمیایی ... ۵۳  
گفتار ۱ ـ ارتباط شیمیایی ... ۵۴  
گفتار ۲ ـ غده‌های درون‌ریز ... ۵۶

فصل ۵ ـ ایمنی ... ۶۳  
گفتار ۱ ـ نخستین خط دفاعی: ورود ممنوع ... ۶۴  
گفتار ۲ ـ دومین خط دفاعی: واکنش‌های عمومی اما سریع ... ۶۶  
گفتار ۳ ـ سومین خط دفاعی: دفاع اختصاصی ... ۷۲

فصل ۶ ـ تقسیم یاخته ... ۷۹  
گفتار ۱ ـ فام‌تن (کروموزوم) ... ۸۰  
گفتار ۲ ـ رشتمان (میتوز) ... ۸۴  
گفتار ۳ ـ کاستمان (میوز) و تولیدمثل جنسی ... ۹۲

فصل ۷ ـ تولیدمثل ... ۹۷  
گفتار ۱ ـ دستگاه تولیدمثل در مرد ... ۹۸  
گفتار ۲ ـ دستگاه تولیدمثل در زن ... ۱۰۲  
گفتار ۳ ـ رشد و نمو جنین ... ۱۰۸  
گفتار ۴ ـ تولیدمثل در جانوران ... ۱۱۵

فصل ۸ ـ تولیدمثل نهان‌دانگان ... ۱۱۹  
گفتار ۱ ـ تولیدمثل غیرجنسی ... ۱۲۰  
گفتار ۲ ـ تولیدمثل جنسی ... ۱۲۴  
گفتار ۳ ـ از یاختۀ تخم تا گیاه ... ۱۳۰

فصل ۹ ـ پاسخ گیاهان به محرک‌ها ... ۱۳۷  
گفتار ۱ ـ تنظیم‌کننده‌های رشد در گیاهان ... ۱۳۸  
گفتار ۲ ـ پاسخ به محیط ... ۱۴۶

فهرست منابع ... ۱۵۳
