# فصل ۵ | توابع نمایی و لگاریتمی

با توجه به نقاط این دو نمودار، جدول زیر را تکمیل کنید.

| نمایی | $2^{-2}=\frac14$ | $2^{-1}=\frac12$ | $2^0=1$ | ... | $2^2=4$ | ... |
|---|---|---|---|---|---|---|
| لگاریتمی | $\log_2\frac14=-2$ | $\log_2\frac12=\ldots$ | ... | $\log_22=1$ | ... | $\log_28=\ldots$ |

به‌طور کلی اگر $a^y=x$ آنگاه $\log_a x=y$ و به عکس. ($a>0$، $a\ne1$، $x>0$)

$$b^a=c\iff\log_b c=a\qquad(c>0,\ b>0,\ b\ne1)$$

### کار در کلاس

|  |  |
|---|---|
| $10^3=1000\to\log_{10}1000=3$ | $\log_8 1=0\to8^0=1$ |
| $9^{1/2}=3\to\log_9 3=\ldots$ | $\log_2(\frac1{16})=-4\to2^{-4}=\ldots$ |
| $4^3=64\to\log_4 64=\ldots$ | $\log_5 125=3\to5^3=\ldots$ |
| $2^5=32\to\ldots=\ldots$ | $\log_{1/3}27=-3\to\ldots=\ldots$ |
| $2^{-3}=\ldots\to\ldots=\ldots$ | $\log_{1/5}125=\ldots\to\ldots=\ldots$ |
| $3^{-2}=\ldots\to\ldots=\ldots$ | $\log_{1/2}16=\ldots\to\ldots=\ldots$ |
