# روابط بین ضرایب و ریشه‌های معادله درجه دوم

## فعالیت

۱. جدول زیر را مطابق نمونه کامل کنید.

| معادله $ax^2+bx+c=0$ | ریشه | ریشه | جمع ریشه‌ها $(S)$ | ضرب ریشه‌ها $(P)$ | $a$ | $b$ | $c$ | $-b/a$ | $c/a$ |
|---|---|---|---|---|---|---|---|---|---|
| $3x^2-5x+2=0$ | | | | | | | | | |
| $4x^2-3x-7=0$ | $-1$ | $7/4$ | $3/4$ | $-7/4$ | $4$ | $-3$ | $-7$ | — | $-7/4$ |
| $x^2-2x+1=0$ | $1$ | | | | | | | | |
| $5x^2+6x-8=0$ | | $4/5$ | | | | | | | |

۲. الف) در جدول بالا بین جمع ریشه‌ها و ضرایب هر معادله چه ارتباطی مشاهده می‌کنید؟

ب) در جدول بالا بین حاصل‌ضرب ریشه‌ها و ضرایب معادله چه ارتباطی وجود دارد؟

۳. اگر $x_1$ و $x_2$ ریشه‌ها و $S$ و $P$ به‌ترتیب حاصل جمع و حاصل‌ضرب ریشه‌های معادله درجه دوم $ax^2+bx+c=0$ باشند، نشان دهید:

$$S=x_1+x_2=\frac{-b+\sqrt\Delta}{2a}+\frac{-b-\sqrt\Delta}{2a}=\cdots=\frac{-b}{a}$$

$$P=x_1x_2=(\qquad)(\qquad)=\qquad=\frac ca$$

به‌طور کلی در هر معادله درجه دوم $ax^2+bx+c=0$ اگر جمع ریشه‌ها $S$ و ضرب ریشه‌ها $P$ باشد این روابط برقرار است:

$$S=\frac{-b}{a},\quad P=\frac ca$$

**مثال:** اگر $x=-1$ یک ریشه معادله $4x^2-mx-7=0$ باشد ریشه دیگر و مقدار $m$ را با استفاده از روابط بین ضرایب و ریشه‌ها به‌دست آورید.

**حل:** اگر $x_1$ و $x_2$ ریشه‌های این معادله باشند، داریم:

$$P=x_1x_2=\frac ca\Rightarrow(-1)x_2=\frac{-7}{4}\Rightarrow x_2=\frac74$$

از طرفی با استفاده از جمع ریشه‌ها داریم:

$$S=x_1+x_2=\frac{-b}{a}\Rightarrow-1+\frac74=\frac m4\Rightarrow m=3$$
