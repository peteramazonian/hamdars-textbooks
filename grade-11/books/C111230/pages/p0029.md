# PDF page 29 — Countable and Uncountable Nouns

**B. Read the following examples. Compare the columns.**

| Singular countable | Plural countable | Uncountable |
|---|---|---|
| a car | two / three / four cars | traffic |
| a book | some / many books | some / much information |
| a bird | lots of / a lot of birds | lots of / a lot of chicken soup |
| a man | few / a few men | little / a little bread |

| Questions | Answers |
|---|---|
| How many cars are there in the street? | There are two / three / four / some / many / lots of / a lot of / a few / few cars. |
| How many books do you need? | I need some / many / lots of / a lot of / a few / few books. |
| How much information does your teacher need? | She needs some / much / lots of / a lot of information. |
| How much bread is there in the kitchen? | There is some / much / lots of / a lot of / a little / little bread. |
