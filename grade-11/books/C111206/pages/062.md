# الْمُعْجَم

| واژه | معنی |
|---|---|
| اُدْعُ | فرا بخوان (دَعا، یَدْعُو) |
| أَنْ لا یَتَدَخَّلَ | که دخالت نکند (تَدَخَّلَ، یَتَدَخَّلُ) |
| تُهَم | تهمت‌ها «مفرد: تُهْمَة» |
| زَلَل | لغزش |
| سَدید | درست و استوار |
| طُوبیٰ لِـ | خوشا به حال |
| عَوَّدَ | عادت داد (مضارع: یُعَوِّدُ) |
| قِلَّة | کمی ≠ کَثْرَة |
| کَلَّمَ | سخن گفت = حَدَّثَ، تَکَلَّمَ (مضارع: یُکَلِّمُ) |
| لا تُحَدِّثْ | سخن نگو (حَدَّثَ، یُحَدِّثُ) |
| لا تَقْفُ | پیروی نکن (قَفا، یَقْفُو) |
| لِکَیْ یُقْنِعَ | تا قانع کند (أَقْنَعَ، یُقْنِعُ) |
| لَیِّن | نرم ≠ خَشِن |
| لین | نرمی ≠ خُشُونَة |
| مَخْبُوء | پنهان = خَفِیّ |
| یُعَرِّضُ | در معرض می‌گذارد (ماضی: عَرَّضَ) |

# عَیِّنِ الصَّحیحَ وَ الْخَطَأَ حَسَبَ نَصِّ الدَّرْسِ.

۱ـ الَّذی یَتَکَلَّمُ فی ما لا یَعْلَمُ، یَقَعُ فی خَطَأٍ. ........

۲ـ مَنْ خافَ النّاسُ مِنْ لِسانِهِ فَهُوَ قَوِیٌّ. ........

۳ـ عَلَیْنا أَنْ لا نَجْرَحَ الْآخَرینَ بِلِسانِنا. ........

۴ـ الَّذی لا یَتَکَلَّمُ لا یُعْرَفُ شَأْنُهُ. ........

۵ـ لا تُحَدِّثْ بِما تَخافُ تَکْذیبَهُ. ........
