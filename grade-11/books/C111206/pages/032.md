# الْمُعْجَم

| واژه | معنی |
|---|---|
| أَجَلّ | گران‌قدرتر |
| آذیٰ | اذیت کرد (مضارع: یُؤْذی) |
| أَزْعَجَ | آزار داد (مضارع: یُزْعِجُ) |
| إِزْعاج | آزار رساندن |
| اِسْتَمَعَ | گوش فرا داد (مضارع: یَسْتَمِعُ) |
| اِلْتَزَمَ | پایبند شد (مضارع: یَلْتَزِمُ) |
| اِلْتِفات | روی برگرداندن |
| اِلْتَفَتَ | روی برگرداند (مضارع: یَلْتَفِتُ) |
| أَلَّفَ | نگاشت (مضارع: یُؤَلِّفُ) |
| الْکُتُبُ التَّرْبَوِیَّة | کتاب‌های تربیتی |
| أَنْشَأَ | ساخت (مضارع: یُنْشِئُ) |
| تارَةً | یک بار = مَرَّةً |
| تَبْجیل | بزرگداشت |
| تَهَرَّبَ | فرار کرد |
| خَجِلَ | شرمنده شد (مضارع: یَخْجَلُ) |
| سَبَقَ | پیشی گرفت (مضارع: یَسْبِقُ) |
| سُلُوک | رفتار |
| عَصیٰ | سرپیچی کرد (مضارع: یَعْصی) |
| فَکَّرَ | اندیشید (مضارع: یُفَکِّرُ) |
| قُمْ | برخیز ← (قامَ، یَقُومُ) |
| کادَ | نزدیک بود که (مضارع: یَکادُ) |
| مَجال | زمینه |
| مُشاغِب | شلوغ‌کننده و اخلالگر |
| وَفّیٰ | کامل کرد (مضارع: یُوَفّی)؛ «وَفِّهِ التَّبْجیلَ: احترامش را کامل به جا بیاور.» |
