# الْمُعْجَم

| واژه | معنی |
|---|---|
| اِتَّقیٰ | پروا کرد (مضارع: یَتَّقیٰ)؛ اِتَّقُوا اللّٰهَ: از خدا پروا کنید |
| إِثْم | گناه = ذَنْب |
| اِغْتابَ | غیبت کرد (مضارع: یَغْتابُ)؛ لا یَغْتَبْ: نباید غیبت کند |
| أَنْ یَکُنَّ | که باشند (کانَ، یَکُونُ) |
| أَنْ یَکُونُوا | که باشند (کانَ، یَکُونُ) |
| بَعْض ... بَعْض | یکدیگر |
| بِئْسَ | بد است |
| تابَ؛ لَمْ یَتُبْ | توبه کرد (مضارع: یَتُوبُ)؛ توبه نکرد |
| تَجَسَّسَ | جاسوسی کرد (مضارع: یَتَجَسَّسُ) |
| تَنابَزَ بِالْأَلْقابِ | به یکدیگر لقب‌های زشت دادن (تَنابَزَ، یَتَنابَزُ) |
| تَوّاب | بسیار توبه پذیر، بسیار توبه کننده |
| خَفِیّ | پنهان ≠ ظاهِر |
| سَخِرَ مِنْ؛ لا یَسْخَرْ | مسخره کرد (مضارع: یَسْخَرُ / مصدر: سُخْرِیَّة)؛ نباید مسخره کند |
| عابَ | عیب‌جویی کرد، عیب‌دار کرد (مضارع: یَعیبُ) |
| عُجْب | خودپسندی |
| عَسیٰ | شاید = رُبَّما |
| فُسُوق | آلوده شدن به گناه |
| قَدْ | گاهی، شاید (بر سر مضارع) «قَدْ یَکُونُ: گاهی می‌باشد» / بر سر فعل ماضی برای نزدیک ساختن زمان فعل به حال و معادل ماضی نقلی است. |
| کَرِهَ | ناپسند داشت (مضارع: یَکْرَهُ) |
| لَحْم | گوشت «جمع: لُحُوم» |
| لَقَّبَ | لقب داد (مضارع: یُلَقِّبُ) |
| لَمَزَ | عیب گرفت (مضارع: یَلْمِزُ) |
| مَیْت | مُرده = مَیِّت «جمع: أَمْوات، مَوْتیٰ» ≠ حَیّ |
