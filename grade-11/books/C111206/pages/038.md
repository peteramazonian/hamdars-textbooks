## التَّمْرینُ الثّانی: تَرْجِمِ الْأَفْعالَ وَ الْمَصادِرَ التّالِیَةَ.

| الْماضی | الْمُضارِعُ وَ الْمُسْتَقْبَلُ | الْأَمْرُ وَ النَّهْیُ | الْمَصْدَرُ |
|---|---|---|---|
| قَدْ أَنْقَذَ: ... | یُنْقِذُ: نجات می‌دهد | أَنْقِذْ: ... | إِنْقاذ: نجات دادن |
| اِبْتَعَدَ: ... | لا یَبْتَعِدُ: دور نمی‌شود | لا تَبْتَعِدْ: ... | اِبْتِعاد: دور شدن |
| اِنْسَحَبَ: عقب‌نشینی کرد | سَیَنْسَحِبُ: ... | لا تَنْسَحِبْ: ... | اِنْسِحاب: عقب‌نشینی کردن |
| اِسْتَخْدَمَ: به کار گرفت | یَسْتَخْدِمُ: ... | اِسْتَخْدِمْ: به کار بگیر | اِسْتِخْدام: ... |
| جالَسَ: همنشینی کرد | یُجالِسُ: همنشینی می‌کند | جالِسْ: ... | مُجالَسَة: ... |
| تَذَکَّرَ: به یاد آورد | یَتَذَکَّرُ: ... | لا تَتَذَکَّرْ: ... | تَذَکُّر: به یاد آوردن |
| تَعایَشَ: ... | یَتَعایَشُ: ... | تَعایَشْ: همزیستی کن | تَعایُش: همزیستی کردن |
| قَدْ حَرَّمَ: حرام کرده است | یُحَرِّمُ: حرام می‌کند | لا تُحَرِّمْ: ... | تَحْریم: ... |
