## التَّمْرینُ الثّانی: تَرْجِمِ الْأَفْعالَ وَ الْمَصادِرَ التّالِیَةَ.

| الْماضی | الْمُضارِعُ وَ الْمُسْتَقْبَلُ | الْأَمْرُ وَ النَّهْیُ | الْمَصْدَرُ |
|---|---|---|---|
| قَدْ أَحْسَنَ: ... | یُحْسِنُ: نیکی می‌کند | أَحْسِنْ: ... | إِحْسان: نیکی کردن |
| اِقْتَرَبَ: نزدیک شد | یَقْتَرِبُونَ: ... | لا تَقْتَرِبُوا: ... | اِقْتِراب: نزدیک شدن |
| اِنْهَزَمَ: ... | سَیَنْهَزِمُ: ... | لا تَنْهَزِمْ: شکست نخور | اِنْهِزام: شکست خوردن |
| اِسْتَغْفَرَ: آمرزش خواست | یَسْتَغْفِرُ: ... | اِسْتَغْفِرْ: آمرزش بخواه | اِسْتِغْفار: ... |
| ما سافَرْتُ: سفر نکردم | لا یُسافِرُ: ... | لا تُسافِرْ: ... | مُسافَرَة: سفر کردن |
| تَعَلَّمَ: ... | یَتَعَلَّمانِ: یاد می‌گیرند | تَعَلَّمْ: ... | تَعَلُّم: یاد گرفتن |
| تَبادَلْتُمْ: ... | تَتَبادَلُونَ: ... | لا تَتَبادَلُوا: عوض نکنید | تَبادُل: عوض کردن |
| قَدْ عَلَّمَ: آموزش داده است | سَوْفَ یُعَلِّمُ: ... | عَلِّمْ: ... | تَعْلیم: آموزش دادن |
