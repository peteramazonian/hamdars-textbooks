## مسیر مطالعه برای ایجنت

۱. درسنامهٔ کوتاه همان درس را باز کن؛ این فایل فقط موضوع و نکات اصلی را معرفی می‌کند.
۲. برای عبارت دقیق، جزئیات، شاهد ادبی یا تمرین، به `source.pdf` کنار همان درسنامه رجوع کن. PDF مرجع اصلی است.
۳. شمارهٔ صفحهٔ PDF کوتاه از ۱ شروع می‌شود؛ نگاشت آن به شمارهٔ چاپی کتاب در درسنامه و `source.json` آمده است.
۴. اگر پیش‌نمایش PDF در ابزار یا GitHub باز نمی‌شود، خود فایل را دانلود کن. دسترسی‌نداشتن را اعلام کن و جای خالی را با حدس پُر نکن.

این فایل‌ها برای آزمودن دسترسی آماده شده‌اند؛ صرف وجود آنها، موفقیت خواندن PDF توسط هر ایجنت یا هر محیطی را ثابت نمی‌کند. برش‌ها متن اصلی، تصویرها و صورت تمرین‌ها را حفظ می‌کنند؛ درسنامه‌ها پاسخ‌نامه نیستند. حقوق متن و تصویرهای اصلی متعلق به صاحبان اثر است.
