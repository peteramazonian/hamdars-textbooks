# نمونه‌های آزمایشی هم‌درس

این پوشه برای آزمایش روش‌های مطالعه و دسترسی به کتاب است و از مجموعهٔ تبدیل‌شدهٔ پایهٔ یازدهم جدا نگه داشته می‌شود.

## مطالعه از PDF، بدون OCR کامل

[فارسی دهم — درس‌های ۱ تا ۳](pdf-first/grade-10/persian/README.md)

در هر پوشهٔ درس، ابتدا `study-guide.md` را بخوانید. برای متن کامل، عبارت دقیق، شعر، تمرین یا جزئیاتی که در خلاصه نیست، `source.pdf` همان پوشه را باز کنید. درسنامه جایگزین متن کتاب نیست.

وجود PDF در GitHub به‌تنهایی تضمین نمی‌کند هر ایجنت بتواند آن را بخواند؛ اگر نمایشگر GitHub در دسترس ابزار نبود، از گزینهٔ دانلود یا پیوند Raw برای دریافت PDF و ابزار خواندن PDF استفاده کنید. اگر ابزار خواندن PDF در دسترس نیست، محدودیت را صریح اعلام کنید و متن را از خلاصه حدس نزنید.
